# 纹理来源与许可

本项目在运行时使用以下图像纹理，均位于 `public/textures/`。若某个文件加载失败，
3D 场景会自动改用程序化生成的替代纹理，并在画面上给出提示，不会出现白屏。

| 文件 | 内容 | 来源 | 授权 |
| --- | --- | --- | --- |
| `earth_day.jpg` | 地球昼面 | [Solar System Scope](https://www.solarsystemscope.com/textures/) `2k_earth_daymap.jpg` | CC BY 4.0 |
| `earth_night.jpg` | 地球夜面 / 城市灯光 | [Solar System Scope](https://www.solarsystemscope.com/textures/) `2k_earth_nightmap.jpg` | CC BY 4.0 |
| `earth_clouds.jpg` | 云层 | [Solar System Scope](https://www.solarsystemscope.com/textures/) `2k_earth_clouds.jpg` | CC BY 4.0 |
| `sun.jpg` | 太阳表面 | [Solar System Scope](https://www.solarsystemscope.com/textures/) `2k_sun.jpg` | CC BY 4.0 |
| `stars_milkyway.jpg` | 银河背景 | [Solar System Scope](https://www.solarsystemscope.com/textures/) `2k_stars_milky_way.jpg` | CC BY 4.0 |
| `earth_normal.jpg` | 地球法线 | [three.js examples](https://github.com/mrdoob/three.js/tree/dev/examples/textures/planets)（底图源自 NASA 公开影像） | MIT |
| `earth_specular.jpg` | 海陆高光遮罩 | [three.js examples](https://github.com/mrdoob/three.js/tree/dev/examples/textures/planets)（底图源自 NASA 公开影像） | MIT |
